
# Игра "Виселица" (Hangman) 😊

# Как играть?

Запустите игру и выберите действие в главном меню. Начните новую игру - выбрав 1. Вводите буквы русского алфавита по одной. Угадывайте слово - каждая правильная буква открывается в слове. Избегайте ошибок - у вас всего 6 попыток!

# 💬 Управление

1 - начать новую игру, 2 - выйти из программы

# 👍 Архитектура проекта

Проект реализован в процедурном стиле с четким разделением ответственности: класс Hangman.java отвечает за основную игровую логику,класс HangmanGraphics.java - за отображение интерфейса и графики, класс WordPressitory.java обеспечивает работу с данными (словами)

# 📌 Особенности реализации

Модульная архитектура, валидация ввода, обработка ошибок

# 🔧 Сборка и запуск

Компиляция всех исходных файлов: javac src/*.java

Запуск из корневой директории проекта: java -cp src Hangman

# 📄 Файл со словами

Игра использует файл resources/words.txt, содержащий русские слова в нижнем регистре (по одному на строку). При отсутствии файла программа корректно завершит работу с указанием абсолютного пути.

# 📄 Лицензия

Проект предназначен для образовательных целей.
